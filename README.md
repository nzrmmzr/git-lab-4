Опис:
Програма реалізує функцію password_ok(password), яка приймає пароль типу str. Вона перевірає пароль на відповідність заданим у завданні вимогам, а саме:

містить від 8 до 32 символів включно
містить щонайменше одну літеру
містить щонайменше одну цифру
не містить пробілів

Якщо пароль не відповідає вимогам, то функція генерує виняток із повідомленням про причину відхилення. Якщо таких причин декілька, програма у повідомленні сповіщує про всі. У разі, якщо пароль підходить, то функція повертає True.


Запуск тестів:
python -m pytest

Запуск тестів із перевіркою покриття:
python -m pytest --cov=password_validator --cov-report=term-missing > coverage.txt 2>
